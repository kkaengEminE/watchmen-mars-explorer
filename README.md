# MARS — The Clockwork Palace

《왓치맨》(Watchmen)의 화성 유리 궁전에서 영감을 받은 **비공식 팬 제작 3D 탐험 프로토타입**입니다.

## 실행

1. `index.html`을 Chrome, Edge, Safari 같은 최신 데스크톱 브라우저에서 엽니다. 일부 브라우저에서 로컬 파일 접근이 제한되면 아래 로컬 서버 방식을 사용하세요.
2. 또는 이 폴더에서 `python3 -m http.server 8000`을 실행한 뒤 `http://localhost:8000`에 접속합니다.
3. 첫 화면에서 **탐험 시작하기**를 클릭합니다. 마우스 포인터 잠금이 허용되지 않아도 **WASD 이동은 계속 작동**하며, 마우스 드래그로 시점을 돌릴 수 있습니다.

> 처음 실행할 때 CDN에서 Three.js와 웹폰트를 불러오므로 인터넷 연결이 필요합니다. 월드 자체는 외부 3D 모델·이미지 에셋 없이 코드로 생성됩니다.

## 조작

| 키 | 동작 |
|---|---|
| `W A S D` | 이동 |
| `마우스` | 둘러보기 |
| `Space` | 점프 (지상) / 상승 (비행) |
| `Space` 빠르게 두 번 | 마인크래프트 크리에이티브 모드처럼 비행 켜기·끄기 |
| `Shift` | 비행 중 하강 |
| `Shift` (지상) / `R` | 빠르게 이동 / 비행 부스트 |
| `V` | 1인칭 / 3인칭 시점 전환 |
| `F` | 비행 모드 전환 (보조 단축키) |
| `E` | 닥터 맨하튼 근처에서 관찰 텍스트 표시 |
| `Esc` | 마우스 잠금 해제 (이동은 계속 가능) |

## 입력 오류 수정 (2026-11-06)

- 이전 버전에서 이동 방향을 계산할 때 `state.yaw` 대신 `state.y`를 참조해 캐릭터 좌표가 `NaN`이 되는 심각한 오류를 수정했습니다. **이 오류가 WASD 이동 시 화면이 사라지는 현상의 주요 원인**이었습니다.
- Pointer Lock 실패·해제 시에도 WASD를 비롯한 이동 입력이 정상 동작하도록 개선했습니다. 잠금 없이 마우스 드래그로 화면을 돌릴 수 있습니다.
- `Ctrl+W`처럼 브라우저 탭을 닫는 단축키와 충돌하지 않도록 빠른 이동은 **Shift(지상) / R(부스트)**로 변경했습니다.
- WebGL 오류 또는 Three.js 다운로드 실패 시 안내 메시지가 표시되도록 했습니다.
- 브라우저 입력 테스트에서 W 전진, D 우측 이동, Space 두 번 비행 전환, 비행 상승, V 시점 전환을 확인했습니다. CDN 연결이 제한된 실행 환경이어서 실제 Three.js 렌더링까지 통합 검증하지는 못했습니다.

## 주요 요소

- 절차적으로 생성되는 화성 지형, 크레이터, 붉은 암석 1,850개, 먼 산맥, 우주 하늘
- 겹쳐 회전하는 4개의 대형 시계 고리, 유리 파편, 첨탑, 연결 통로, 반투명 크리스털
- 공중에 떠 있는 빛나는 파란 인체 형상과 에너지 파티클
- 외부 애셋 없이 만들어진 3인칭 탐험가 캐릭터
- 이동, 점프, 창의 모드 비행, 자유 카메라

## 개발 메모

- 단일 HTML + Three.js ES Module, 빌드 과정이 필요하지 않습니다.
- 이 팬 콘셉트는 영화의 실제 3D 모델과 텍스처를 사용하는 것이 아니라, 화성의 거대한 시계장치 형태의 유리 궁전에서 영감을 얻어 절차적으로 재구성한 장면입니다.
- 영화 및 원작의 권리는 원권리자에게 있습니다. 상업 배포하려면 권리 검토가 필요합니다.


## GitHub Pages 배포 (정적 사이트)

이 프로젝트는 빌드가 필요 없는 정적 HTML 사이트이므로, 가장 간단한 방식은 `main` 브랜치 루트를 GitHub Pages에 게시하는 것입니다.

1. GitHub에서 `kkaengEminE/watchmen-mars-explorer` 공개 저장소를 만듭니다.
2. `index.html`, `.nojekyll`, `README.md`를 저장소 루트에 업로드합니다.
3. `Settings → Pages → Build and deployment`에서 **Deploy from a branch**를 선택합니다.
4. 브랜치 **main**, 폴더 **/(root)**를 선택하고 **Save**를 누릅니다.
5. GitHub Actions의 `pages build and deployment` 완료 이후 아래 URL에 접속합니다.

예상 주소: https://kkaengemine.github.io/watchmen-mars-explorer/

`main`에 변경 사항을 푸시하면 GitHub Pages가 다시 배포합니다. HTML은 Three.js CDN을 사용하므로 인터넷 연결이 필요합니다.

**다른 프레임워크로 제작한 사이트에서는** 빌드가 필요할 수 있습니다. 그때는 GitHub Actions 기반 CI/CD를 사용하는 것이 적합합니다.
